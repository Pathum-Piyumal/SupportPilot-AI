# API contracts

Implemented routes:

| Method | Route           | Result                                                       |
| ------ | --------------- | ------------------------------------------------------------ |
| GET    | `/health/live`  | `{"status":"ok"}`                                            |
| GET    | `/health/ready` | `{"status":"ready"}` when PostgreSQL responds; otherwise 503 |

Errors use `{"error":{"message":"...","request_id":"..."}}`. Responses include an `X-Request-ID` generated by the server. OpenAPI is available at `/openapi.json`, with interactive documentation at `/docs`. Business endpoints will be added under `/api/v1` as their features are implemented.
